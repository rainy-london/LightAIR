Overview

01 / Overview

Finding the action, not just the person

Text-based person anomaly search must match both macro-level appearance and micro-level behavior. Dominant appearance cues can swallow subtle action signals, while hard negatives encourage harmful optimization shortcuts.

01

Action signals are subtle

Fine-grained behaviors occupy a much weaker signal than clothing, color, and identity.

02

Appearance features dominate

Pixel-level entanglement contaminates action representations and weakens retrieval.

03

Hard negatives invite shortcuts

Same-appearance, different-action samples can push optimization off the semantic manifold.

02 / Method

A geometric route to clean action semantics

LightAIR separates action from appearance in the forward pass, then preserves that separation during optimization.

01

Action Inversion Operator

Reconstructs pure action features from a frozen text-derived semantic codebook.

02

Orthogonal Null-Space Projection

Constrains appearance features to the orthogonal complement of the action subspace.

03

Gradient Rectification

Projects updates onto a Riemannian tangent space to suppress harmful shortcuts.

Abstract

LightAIR addresses visual decoupling failure and shortcut learning in text-based person anomaly search. It reconstructs action features from textual semantic anchors, projects appearance into the orthogonal complement of the action subspace, and rectifies optimization along a Riemannian tangent space. Experiments on TPAS and TIPR benchmarks show consistent state-of-the-art performance.

The implementation builds on X2-VLM and evaluates TPAS with the PAB benchmark. See the repository README for installation, data preparation, and evaluation instructions.
